# Portfolio Account Soft Delete

## Goal

在 Portfolio 页面增加安全的“删除账户”能力。删除是软删除：账户被标记为停用，所有持仓、交易、现金流水、企业行为、策略目标和快照历史均保留。

## Rules

- 已绑定策略的账户禁止删除，必须先解绑策略。
- 默认账户列表只返回 active 账户。
- 用户可以切换“显示停用账户”查看已停用账户，但停用账户不可录入新交易、绑定策略或再次删除。
- 删除操作必须经过确认弹窗。
- 删除成功后当前视图刷新；如果当前选中账户已停用，切换到“全部账户”。
- 不执行物理 DELETE，不改变历史业务数据。

## API

- `DELETE /api/v1/portfolio/accounts/{account_id}` 标记 `is_active = 0` 并返回账户实体。
- 账户已绑定策略返回 `409`。
- 账户不存在返回 `404`。
- 已停用账户重复删除返回 `409`。

## UI

- 账户操作区为当前 active、单账户视图显示“删除账户”危险操作。
- 增加“显示停用账户”开关，调用现有 `include_inactive` 查询参数。
- 停用账户以状态文字/Badge 展示，不显示删除、解绑和写入操作。
