# 成长股策略失败复盘(2026-06-11)

> **目标**:在 A 股 2010-2026 区间(16.4 年),通过「成长股选股」框架达成 ≥ 15% CAGR
>
> **结论**:**11 个变体全部失败**,最优变体仅 4.3% CAGR(GARP+MacroTiming),离目标差 ~11pct;7 个变体为负收益;maxDD 普遍 60-85%,远超 baseline 低估值的 26.7%
>
> **决策**:**关闭「单一选股逻辑 × 可选 timing」赛道**,后续若要拼 15% CAGR 必须切换思路(多因子合成 / 行业轮动 / 跨市场配置 / 量化择时对冲),作为独立 plan 立项

## 3. 共性诊断

11 个变体覆盖了 4 个正交方向,**全部失败**:

| 方向 | 代表 | 结果 |
|---|---|---|
| 财务高增长(EPS YoY) | GARP v1-6, Lynch v1-2 | 0.17~0.91× / -0.61~-0.40× |
| 财务质量(ROE 持续) | Buffett-Quality | -0.47× |
| 估值锚(PEG) | Lynch v1-2 | -0.61~-0.40× |
| 价格驱动(动量) | MomentumValue | -0.54× |
| 大盘择时(CSI300 MA200) | GARP-MacroTiming, Lynch v2 | 救场 ~30pct,无法翻盘 |

### 3.1 为什么财报选股在 A 股 16 年区间不工作

1. **「连续高 EPS YoY」≈ 周期股顶部触发器**
   2017-21 钢铁/煤炭/化工/有色/猪肉典型 — 业绩爆发那年正是周期顶,选入即套牢。Lynch 美股 1980-90s 数据中"持续高增长"是消费/科技结构性赛道,A 股结构本质不同
2. **A 股财报噪声大**
   一次性损益 / 资产重组 / 商誉减值脉冲多;IPO 后 3 年业绩普遍粉饰;"扣非净利"也无法完全过滤
3. **PEG 锚失效**
   流动性溢价 + 题材炒作让"便宜成长股"长期更便宜,均值不回归
4. **"机构抱团白马"反 alpha**
   连续 3 年 ROE≥15% 选出来的多是消费/医药龙头,2021 后估值切割期暴跌 50%+

### 3.2 为什么动量也不工作

11 号变体已证明:6M 动量 + PB 价值 + 月度调仓在 A 股 16 年区间 -54%。
- 月度调仓换手率太高(2152 trades)— 佣金 + 滑点累积大
- A 股动量在 2018/2024 这种崩盘后的反转行情中**全错信号**(强者恒强失效,反转行情中刚买入就回吐)

### 3.3 为什么大盘择时不够用

CSI300 MA200 timing 唯一带来正收益,但 maxDD 只压了 8pct:
- **MA200 滞后严重**:2018/2022/2024 跌穿 MA200 时指数已跌 15-20%,而成长股 beta>1 已跌 30-40%
- **月度调仓盲区**:中间月份崩盘看不到,要等下一个调仓月
- **震荡市假信号多**:刚清仓又站上、刚买入又跌穿

## 4. 引擎与数据健康性自检

排除假阳性失败:

- ✅ baseline (`0b440b64`) 同引擎跑出 12% CAGR,引擎无系统性偏差
- ✅ 数据来源统一 DuckDB (`v_a_daily / v_a_indicator`),无 look-ahead(NOTICE_DATE-aware)
- ✅ 11 变体 trades 数量合理(361~2152),与调仓频率一致,无异常交易爆发
- ✅ qfq 前复权,无除权除息断点
- ⚠️ **未排除幸存者偏差**:`v_a_daily` 不包含已退市股票回测期价格,可能小幅高估全部策略(包括 baseline)

## 5. 后续赛道设计(独立立项,非本会话执行)

11 变体覆盖完单一选股 × 可选 timing 后,要拿 15% CAGR 必须切换框架:

### A. 多因子合成(IC 加权)
- 把 ROE / PB / 动量 / 资产负债率 / 净利稳定性 ~5 因子做横截面 z-score,按历史 IC 加权合成评分
- 月频按合成评分前 N 选股
- 关键:**单因子排序 → 多因子合成**,降低单维度噪声敏感性
- 风险:数据挖掘陷阱,需要走 `make-plan` 严格 OOS 验证

### B. 行业轮动(申万一级)
- 按月排申万一级行业最近 6 月动量,选**前 3 强势行业**内市值带 50-300 亿股票,等权
- 加 CSI300 MA200 风险开关
- 数据需求:`v_a_industry`(若 DuckDB 已有)否则需 EastMoney 行业字段补齐
- 文献:A 股行业 momentum 比个股 momentum 显著

### C. ETF 全仓 + 择时(最简,可能最有效)
- 沪深300 ETF / 中证500 / 创业板 ETF 三选一仓位
- 信号:CSI300 close > MA200 满仓最强动量 ETF;否则空仓 / 国债
- 优点:30 行代码可实现,无个股选错风险
- 预期:有可能直接 ~10-15% CAGR,因为吃满指数收益 + 避开熊市

### D. 跨市场配置(A+港股+美股)
- 月频按 3 市场过去 12 月夏普比加权
- 利用 yfinance + DuckDB v_hk_daily / v_us_daily(已就绪)
- 美股长期 trending bull 大幅拉低组合波动

## 6. 结论

- **现状**:单一选股 × 可选 timing 框架已穷举,A 股 2010-2026 区间无法达到 15% CAGR
- **决策**:关闭本赛道。新代码停止该方向迭代
- **保留产物**:
  - `strategies/utils/growth.py / growth_long.py / index_timing.py` — 工具,新赛道仍可复用
