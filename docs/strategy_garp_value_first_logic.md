# A股「合理价格成长 · 价值优先」策略 —— 完整逻辑说明

> 代码位置:`backend/services/backtest/strategies/deployed/garp_value_first_strategy.py`

> 底座父类:`LowValuationMultiFactorQuarterlyStrategy`(低估值多因子季度调仓)
> 支撑模块:`utils/growth.py`(成长门)、`utils/financial.py`(净资产收益率)、`utils/quality.py`(价值陷阱过滤)、`utils/yield_factor.py`(股息率)、`utils/st_filter.py`(风险警示股过滤)

本文不使用任何英文缩写,所有指标一律写明全称。读者无需阅读源码即可完整理解该策略「选什么股、什么时候买卖、买多少」的全部规则。

## 一、术语对照(先把缩写讲清楚)

| 本文使用的全称 | 含义 | 数据来源 |
|---|---|---|
| **市净率** | 当前股价 ÷ 最近一期每股净资产。衡量股价相对账面净资产的溢价。数值越小越「便宜」。 | 日线行情估值字段 |
| **滚动市盈率** | 当前股价 ÷ 过去十二个月每股盈利。衡量「为每一元盈利付出多少钱」,越小越便宜。 | 日线行情估值字段 |
| **净资产收益率** | 归属母公司净利润 ÷ 净资产,衡量股东每一元本金的盈利能力,越高越好。 | 年度报告(财务指标) |
| **滚动股息率** | 过去十二个月每股现金分红 ÷ 当前股价。衡量「现金分红回报率」,越高越好。 | 分红数据 + 日线价格 |
| **经营活动现金流量净额** | 公司主营业务实际收到的现金减去付出的现金。用来检验「账面利润是否有真金白银支撑」。 | 年度报告(现金流量表) |
| **资产负债率** | 总负债 ÷ 总资产,衡量公司财务杠杆与偿债压力,越高越危险(金融业除外)。 | 年度报告(资产负债表) |
| **归属母公司净利润同比增速** | 本期归属母公司净利润相对去年同期的增长百分比。本策略的「成长」尺子。 | 年度报告(利润表) |
| **标准分数(标准化)** | 把一组数值减去其平均值、再除以标准差,转换成「均值为零、标准差为一」的可比尺度。用于把市净率、净资产收益率等量纲完全不同的指标放到同一把尺子上相加。 | 由原始因子计算 |
| **复合评分** | 把多个标准化后的因子按权重相加得到的总分,作为最终排序依据,分数越高越优先买入。 | 由多个因子计算 |
| **动量** | 过去一段时间的累计涨跌幅,衡量价格近期强弱。 | 日线行情 |
| **风险警示股(特别处理)** | 因财务异常等被交易所标记、有退市风险的股票(股票名称前带特殊标记)。本策略一律排除。 | 风险警示判定模块 |
| **财报公告日** | 财务报表真正对外公布、投资者能看到的日期(晚于报告期末)。本策略一律以公告日判断「这份财报当时是否已可见」,严防使用未来信息。 | 财务数据中的公告日字段 |
| **等权重** | 持仓里每只股票分得相同比例的资金。 | —— |
| **波动率倒数加权** | 波动越小的股票分得越多资金的加权方式(可选)。 | 日线行情 |
| **当日买入次日才可卖出规则** | 今天买入的股票最早要到下一个交易日才能卖出。 | 回测撮合引擎强制执行 |

## 二、策略一句话定位与核心思想

**这是一个「价值优先、成长把关」的策略:先在 A 股全市场里筛出「又便宜、又优质」的股票(低市净率、低市盈率、净资产收益能力达标、且无财务造假/价值陷阱嫌疑),再用「成长门」把其中「便宜但正在衰退」的公司剔除掉,只保留「便宜、优质、且仍在成长」的股票,按多因子复合评分排序选出一篮子等权持有,每季度调仓一次。**

关键在于「**价值优先**」四个字,它和另一种思路截然相反:

- **本策略(价值优先)**:估值便宜是前提,成长只是一道「过滤门」,目的是**剔除价值陷阱**(便宜是因为公司在衰退),而**不是去追逐高成长**。
- **被证伪的反面思路(成长优先)**:先按成长率挑出高增长股票,再检查估值。这种思路在 A 股全周期回测中已被证明无效,因此本策略坚决不采用。

一句话:**「在便宜且优质的股票里,只买还在成长的。」**

---

## 三、整体运行节奏

这是一个**按季度定期调仓**的策略:

1. 回测引擎按月触发策略逻辑(策略频率固定为「每月」,不可外部更改)。
2. 但**真正重新选股只在调仓月份发生**,默认是 **3 月、6 月、9 月、12 月**(每季度一次)。非调仓月份不重新选股。
3. **例外**:如果开启了止损/止盈(默认关闭),则**每个交易日**都会检查持仓是否触发止损或止盈线,这一检查独立于调仓节奏(详见第五节)。

## 四、选股逻辑(只在调仓月份执行)

到了调仓月份,策略对全市场股票依次执行下面的层层筛选。任何一步不通过,该股票当场出局。

### 第零步:成长门(本策略相对底座新增的关键一层,最先执行)

在把股票交给价值底座筛选**之前**,先用「成长门」收敛候选范围:

- 取该股票截至当前日期**已公告**的最新「归属母公司净利润同比增速」。这里采用**财报公告日口径**:只有财报真正公布、当时能看到的数据才会被使用,绝不偷看当时尚未披露的财报(严防未来信息)。
- **若同比增速达到下限则保留**。默认下限为 **0%**,即只要求「净利润同比非负(不是负增长)」,这就是当前发布版本(代号 g0)的设定——它把成长门当作「**剔除正在衰退的公司**」的工具,而非「追求高增长」。
- **若该股票未披露成长数据(查不到同比增速)**:由参数决定取舍。默认设为「**剔除**」(保守口径)——宁可错过数据缺失的票,也不放进无法验证成长性的标的。

> 设计上,成长门只在调仓月份计算。非调仓月份父类本就直接返回空清单,无需扫描全市场的成长表,以节省算力。

通过成长门的股票,才进入下面价值底座的五个阶段筛选。

### 阶段一:估值便宜 + 非风险警示股 + 数据新鲜(四联过滤)

对每只候选股票检查:

1. **估值数据必须存在且新鲜**:必须有当日可用的估值数据,且数据日期距今不能太久(默认上限为「时效参数的两倍」,即五个交易日的两倍),防止退市/停牌股用陈旧数据混入。
2. **市净率必须为正,且不超过上限(默认上限 1.0)**:即只买「股价低于或等于每股净资产」的破净股。市净率为负(净资产为负)或缺失的排除。
3. **滚动市盈率必须为正,且不超过上限(默认上限 30 倍)**:亏损公司(市盈率为负)排除;市盈率过高(太贵)的也排除。
4. **必须不是风险警示股**:被交易所特别处理、有退市风险的股票一律排除。

### 阶段二:质量过滤(剔除「价值陷阱」)

便宜不等于好——有些股票便宜是因为基本面在恶化,即所谓「价值陷阱」。本阶段用四道财务体检把它们筛掉(**金融行业——银行、保险、证券、信托、金融控股——因其资产负债结构特殊,以下相关检查予以豁免**):

1. **经营活动现金流量净额必须为正(默认开启,金融业豁免)**:公司主营业务得真正在收钱,而不是只有账面利润。
2. **经营活动现金流量净额 ÷ 净利润 ≥ 下限(默认 0.5,金融业豁免)**:账面利润里至少有一半要有真实现金支撑,以剔除「靠应收账款堆出来的假利润」。
3. **资产负债率 ≤ 上限(默认 70%,金融业豁免)**:杠杆过高、偿债压力大的公司排除。
4. **净资产收益率不得连续两年大幅下降(默认开启)**:若公司盈利能力连续两年显著恶化(连续两年下降幅度达到约 30%),视为质量恶化信号,排除。

任一项不通过即出局,并记录被剔除的原因。

### 阶段三:净资产收益率(盈利质量门槛)

取该股票截至当前日期**已公告**的最新**年度报告**净资产收益率(同样采用财报公告日口径防未来信息;只用年报,不用季报/半年报,以保证口径一致)。若该值缺失或不高于下限(默认 8%),排除。

### 阶段四:动量过滤(剔除最弱的一批)

对剩余股票,计算各自过去一段时间(默认 120 个交易日,约半年)的累计涨跌幅(动量)。然后**剔除动量最差的一个分位段**(默认剔除最差的 30%)。这一步避免买入正处于明显下跌趋势中的股票。剔除比例可设为 0 表示不过滤。

### 阶段五:多因子复合评分排序

到这一步剩下的都是「便宜 + 优质 + 在成长 + 不太弱」的股票。最后用一个**多因子复合评分**给它们排序,而不是只看单一指标(只按市净率排序会让破净银行扎堆,无法区分质量)。

复合评分的构成:把以下因子各自做标准化(转成均值为零、标准差为一的可比尺度),再按权重相加:

```
复合评分 =   权重₁ × 标准化(市净率的倒数)        ← 越便宜得分越高
           + 权重₂ × 标准化(净资产收益率)          ← 盈利能力越强得分越高
           + 权重₃ × 标准化(滚动股息率)            ← 分红回报越高得分越高
           + 权重₄ × 标准化(滚动市盈率的倒数)      ← 盈利估值越便宜得分越高
           + 权重₅ × 标准化(逆动量)                ← 可选,跌得越多得分越高(默认关闭)
```

当前发布版本(g0)的权重设定:

- 市净率倒数权重 = **1.0**
- 净资产收益率权重 = **1.0**(原本曾设为 2.0,经分段样本外验证「无依据」后退回等权,这是「减少过拟合」的方向)
- 滚动股息率权重 = **2.0**(给现金分红回报更高的话语权)
- 滚动市盈率倒数权重 = **1.0**
- 逆动量权重 = **0.0**(默认关闭)

评分越高的股票排序越靠前。

### 阶段六:行业集中度去重 + 取前若干名

从评分最高的股票开始依次纳入,但**同一个一级行业最多只能纳入设定的只数(默认 2 只)**,直到凑满目标持仓数量(默认 30 只)。

- **为什么要限制每行业只数**:A 股的破净股票池高度集中在银行、地产、钢铁等少数几个行业,如果不加限制,组合会被这几个行业垄断。强制每行业最多 2 只,确保组合跨足多个行业、分散行业风险。经分段样本外回测验证,把「每行业上限」从 3 收紧到 2,在全周期带来年化约 +2.1 个百分点、最大回撤下降约 5.8 个百分点的结构性改善(且在牛市、熊市、震荡市等多种行情下稳健,并非依赖单一行情)。
- **关于目标持仓数量 30 只**:这是一个「冗余值」。由于前面层层过滤后,实际平均持仓往往只有约 10 只,所以这个上限通常并未真正起约束作用(设成 20 或 50,回测结果几乎一致)。

最终选出的这批股票,即本期目标持仓。

## 五、交易执行逻辑(怎么卖、怎么买、买多少)

**所有买入遵守「当日买入次日才可卖出」规则;成交价采用「(开盘价 + 收盘价) ÷ 2」中间价,并计入佣金、印花税与买卖价差等成本(由回测撮合引擎统一处理)。**

### 卖出环节(两个触发条件)

1. **每个交易日:止损/止盈检查(默认关闭)**
   如果设置了止损线或止盈线,则每个交易日检查每只持仓相对其买入成本的盈亏:
   - 亏损达到止损线(例如下跌 20%)→ 立即清仓该股;
   - 盈利达到止盈线(例如上涨 50%)→ 立即清仓该股。
   被止损/止盈卖出的股票会同时从「本期目标持仓」里移除,防止调仓当天又被买回。默认止损线和止盈线都为 0,即**不启用**,卖出完全由季度调仓驱动。

2. **调仓日:清掉所有不在新目标清单里的持仓**
   到调仓日,凡当前持有但不在新选出的目标清单里的股票,全部清仓卖出;已在目标清单里的则保留。这就是「定期整体换股」。

### 买入环节:决定每只股票买多少

对目标清单里的股票分配资金,有两种方式:

1. **等权重(默认)**:每只目标股票分得相同比例的资金。例如目标 10 只,则每只约占总资产的十分之一。

2. **波动率倒数加权(可选)**:让波动越小(越稳)的股票分得越多资金。具体按「1 ÷ 该股票近 60 个交易日的日涨跌幅标准差」的比例分配;算不出波动率或数据不足的股票,用其他股票波动率的中位数兜底;若全部失败则退回等权。

**最终下单方式**:对每只目标股票,下达「把持仓调整到对应目标比例」的指令,回测引擎据此撮合买入。

> 说明:本策略**始终满仓**配置(目标比例之和接近 100%),没有像港股策略那样的「大盘环境择时降仓位」机制。

## 六、防止使用未来信息(关键的诚信设计)

财务数据(净利润同比增速、净资产收益率、现金流、负债率等)全部采用**财报公告日口径**:某份财报只有在其「真正对外公布的日期」早于或等于当前回测日期时,才被认为「当时可见、可以使用」。这样可以严格避免「一到报告期末就假设已知财报」的未来信息偏差(那会让回测结果虚高、不真实)。

而市净率、滚动市盈率等估值指标来自逐日更新的行情数据,天然只反映「当日及以前」的信息,本身就不含未来信息。

---

## 七、已知边界与说明

1. **始终满仓、无大盘择时**:本策略不做指数择时降仓,熊市同样满仓持有,靠「便宜 + 分散 + 质量」抵御风险,而非靠空仓避险。
2. **成长门当前是「非负门」而非「高增长门」**:发布版本只要求净利润同比非负,目的是排除衰退股,而非筛选高增长股(后者方向在 A 股已被证伪)。
3. **金融股的部分质量检查被豁免**:银行/保险/证券等行业资产负债率天然极高,若不豁免会被误杀,因此对这些行业的现金流与负债率检查予以放行。
4. **目标持仓数量 30 只是冗余上限**:实际平均持仓约 10 只,该值通常不构成真实约束。

## 九、整体流程图(文字版)

```
每月触发
   │
   ├─ 当月是否为调仓月份(默认 3/6/9/12 月)?
   │     │
   │     ├─ 否 → 不选股(但若开启止损/止盈,仍每日检查持仓)
   │     │
   │     └─ 是 → 进入完整选股流程:
   │              │
   │              ├─ 第零步·成长门:归属母公司净利润同比增速 ≥ 0(公告日口径)?
```
