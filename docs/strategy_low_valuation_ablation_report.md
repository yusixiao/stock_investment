# 低估值季度调仓策略 — Ablation 总结报告

**日期**:2026-06-10
**基线策略**:`LowValuationQuarterlyStrategy`
**实验策略**:`LowValuationMultiFactorQuarterlyStrategy`(可参数化退化为 baseline)
**回测区间**:2010-01-01 ~ 2026-06-09(16.5 年)
**市场**:A 股全市场
**初始资金**:1,000,000 元
**调仓节奏**:5 / 9 / 11 月各一次(默认)
**仓位**:等权 1/N(默认 N=15)

## TL;DR

跑了 **18 个变体**,**全部跑不赢 baseline**。最接近的是 v15(SL=30% 单股止损),收益仅落后 baseline 1.9%,maxDD 完全相同,可视为「无害的安全网」。

**核心结论**:baseline 的 4 大基本特征(最低 PB 单因子排序 + ROE≥5 / 等权 1/N / 5-9-11 季度调仓 / 不止损不止盈)是该参数空间的**全局最优**。alpha 来源 = **最便宜+不完美的反转股**,任何「质量」「动量」「波动」纠偏都把它们挤掉。

## 关键洞察

### 1. 质量过滤是负贡献(v1 / v3)

CFO 正、CFO/净利润≥0.5、资产负债率≤70%、ROE 不大跌 这套教科书级"价值陷阱排查"在数据上**严重负贡献(-47%)**。原因:

- 价值反转股的 alpha 恰恰来自「**财务暂时不完美 → 估值被打到地板 → 反转**」的过程
- 把不完美的全过滤掉,留下的是「估值低但已经稳定」的股票,反转弹性大幅缩水
- A 股低 PB 池子中,银行/钢铁/建筑等周期股占大头,它们的 CFO/资产负债率天然不达标

**银行业豁免也救不回来** — 因为豁免后还是要在质量股池里挑,而质量股池的反转 alpha 已经被市场充分定价。

### 2. 多因子复合 score 是负贡献(v1 / v5 / v12 / v13)

z-score 加权 1/PB + ROE + 股息率 + 1/PE 的"复合估值"思路反而**伤害收益(-42%)**。

加上逆动量(z(-momentum))后**灾难级负向(-78%)** — 把"既便宜又跌得多"的股票排前面,吸引到的是**真崩盘股**(下跌趋势中的死亡螺旋),而不是反转股。

**单 PB 排序就是最好的 PB 排序**。

### 3. 行业集中度限制是负贡献(v1 / v4 / v7)

cap=3 / cap=5 都跑输 baseline。深破净银行扎堆**不是 bug,是 feature** — 银行股 2014-2024 的修复行情贡献了 baseline 大量收益。

### 4. 调仓频率改月度是灾难(v10)

每月调仓 → 收益 -36% / **maxDD 翻倍到 38%** / 交易笔数 2659(基线 737 的 3.6 倍)。手续费和滑点吃掉绝大部分 alpha,且高频换手放大了系统性风险敞口。

**5/9/11 季度调仓是经过验证的节奏**,跨过年报披露(4月)+ 中报披露(8月)+ 三季报披露(10月)三个事件窗口,捕获基本面变化后的估值修复。

### 5. inv_vol 反向波动加权:小幅减 DD,代价过大(v11)

maxDD 26.69% → 25.83%(减 0.86pct),收益 -16%。**性价比不划算**。

原因:σ_60 在季度间漂移导致仓位频繁微调,turnover 上升;同时低波动股恰恰是已经稳定的标的,反转弹性弱。

### 6. 个股止损/止盈基本无效(v14-v18)

| 操作 | 效果 |
|---|---|
| SL=20% 太紧 | 误伤反转股,-11% |
| **SL=30% 刚好** | **基本持平 baseline(-1.9%),纯安全网** |
| TP=50% | -39% 灾难,提前砍掉多倍股长尾 |
| TP=100% | -17%,即使阈值很宽也是负向 |

**最关键的一点**:SL=30% maxDD 完全没变(26.69%),证明**组合层面的 DD 由系统性风险主导**(2015 股灾、2018 贸易战、2022 疫情封控),个股止损压不下来组合 DD。

要压 DD 必须做**市场择时 / 总仓位管理**,而不是个股止损。

### 7. top_n 集中/分散都伤(v8 / v9)

- top10 集中:-6%
- top20 分散:-14%

baseline top15 是甜蜜点。

## 唯一勉强可接受的改动

**v15 (SL=30%)** — 损失收益 1.9%,maxDD 完全不变,但提供单股极端崩盘的安全网(主观心理价值)。

**结论:不建议默认开启**,但策略类已支持(`stop_loss_pct` 参数),用户可在配置层选择性启用。

## baseline 不可动摇的 4 大特征

经 18 变体验证,以下 4 项是 alpha 来源,**任何修改都是负向**:

1. **最低 PB 单因子排序**(不要混入 ROE/股息率/动量)
2. **ROE ≥ 5%**(不要抬高到 8/10/12)
3. **等权 1/N**(不要 inv_vol、不要市值加权)
4. **5/9/11 季度调仓**(不要月度,也不要止盈)

辅助但弹性较大的参数:

- top_n=15(±5 都还可以)
- pb_max=1.0(可调)
- 不止损 / 不止盈(SL=30% 是唯一勉强可接受的扩展)

## 真正可能的优化方向(本轮未做)

1. **市场择时**:基于上证指数 200 日均线 / PE 百分位决定满仓 / 半仓 / 空仓,目标压缩系统性 maxDD 而不损失 alpha
2. **港股 / 港股通市场重做 baseline**:验证 A 股的 alpha 是否在港股可复现(港股低估值 + 高股息可能更显著)
3. **逐年归因分析**:把 baseline 收益按年拆开,看哪些年份贡献了主要 alpha,哪些年份持平或亏损,识别失效环境
4. **股息再投资**:当前回测假设股息留现金,改为再投资后预期收益更高(但需求确认 broker 是否支持)
