## 策略逻辑

### 为什么有效？

1. **GARP基础**：PE≤12 + 高成长 + 高ROE，选出"便宜的好公司"
   - PE≤12比常规15更严格，安全边际更高
   - 净利润CAGR≥15%确保真成长，不是价值陷阱
   - ROE≥10%确保盈利质量

2. **动量点火**：6个月>20% + 1个月>0，确认市场开始认可
   - 好公司可能长期被低估，动量告诉我们"启动时刻"
   - 双动量过滤假突破（6个月强但1个月转弱的剔除）

3. **动量排序**：按6个月动量取前12，而非PEG排序
   - 核心洞察：动量强度 > 静态估值指标
   - 强动量 = 市场共识形成，跟随趋势

4. **风险控制**：
   - MA90确保中期趋势向上
   - Turnover≥1000万保证流动性
   - 行业≤2只分散风险
   - 季度调仓平衡换手与及时性

### 与前任冠军的演进

```
opt23 (24.81%) → GARP + 6个月>20%强动量
opt34 (26.66%) → + 1个月>0双动量确认
opt48 (30.19%) → + 按动量排序（代替PEG排序），突破30%
opt64 (32.63%) → + PE≤12深价值，突破32%
```

两次突破都来自**经济逻辑**，非参数挖掘：
- opt48：动量强度比静态PEG更能识别赢家
- opt64：更便宜的好公司 + 动量 = 更高赔率
