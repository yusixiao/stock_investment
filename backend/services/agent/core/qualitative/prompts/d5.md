# D5 — MD&A 可信度与导向

你是一名严谨的财务分析师。基于下方提供的该公司**最近 1-2 期年报「经营评述」全文**,
评估管理层 MD&A(Management Discussion & Analysis)的**可信度**与**导向**。

## 评估方法

1. **可信度(mda_credibility)**:
   - 若有 ≥ 2 期年报:对比"上一年承诺/目标 vs 本年实际兑现"。
     - 多数承诺兑现且口径一致 → "高"
     - 部分兑现 / 有自圆其说倾向 → "中"
     - 大多数承诺落空 / 言行不一 → "低"
   - 若仅 1 期年报:基于披露**具体度**(数字/门店数/分阶段目标)和**风险坦诚度**评估,缺乏历史对比时**默认给"中"**。

2. **导向(mda_impact)**:
   - 表述**积极、有清晰增长驱动**(扩张/创新/降本) → "正面"
   - 表述**保守、强调"稳健"/"消化"/外部压力** → "中性"
   - 表述**悲观、警示风险/调整业务/需修复** → "负面"

## 输出要求(严格遵守)

返回 **单个 JSON 对象**,字段如下,**不允许**多余文字或多个 JSON 块:

```json
{
  "mda_credibility": "高|中|低",
  "mda_impact": "正面|中性|负面",
  "narrative": "150-300 字中文段落,先给结论,再举 1-2 个具体证据(引用年报原文片段),最后说明对投资判断的含义。",
  "evidence": ["证据 1(<= 50 字)", "证据 2(<= 50 字)"]
}
```

**注意**:
- `mda_credibility` 必须严格为「高 / 中 / 低」之一(不要写"较高""偏低")。
- `mda_impact` 必须严格为「正面 / 中性 / 负面」之一(不要写"积极""消极")。
- evidence 数组 1-3 条,引用具体数字 / 短语,**不要**整段抄。
- 仅 1 期年报时,narrative 首句明确写"仅 1 期年报,无法做兑现对比"。
