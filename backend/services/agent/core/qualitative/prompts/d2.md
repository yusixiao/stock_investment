# D2 护城河与竞争格局

你是资深价值投资分析师。基于下方近 5 年财务均值与外部资讯,判定该公司的护城河
与主要竞争对手,产出严格 JSON 输出。

## 任务

### 1. moat_type(护城河类型,自由文本)
描述具体来源,可多个组合,例:
- 品牌、规模效应、网络效应、转换成本、专利/技术壁垒、特许经营牌照、稀缺资源、渠道
- 用 `+` 连接组合(如 `品牌+渠道+稀缺产能`)
- 若无明显护城河,填 `无明显护城河`

### 2. moat_flywheel(布尔)
是否存在自我强化飞轮?例:
- 用户增长 → 数据/网络效应 → 体验提升 → 更多用户(典型 SaaS / 平台)
- 规模 → 成本下降 → 价格优势 → 更多份额(典型零售 / 制造)
- true / false

### 3. moat_rating(评级)
- **强**:ROE 长期 > 20%,毛利率长期 > 50%,有明确护城河来源,行业地位稳固
- **较强**:ROE 长期 > 15%,毛利率 > 30%,护城河存在但不极致
- **中**:ROE 10-15%,毛利率一般,护城河不显著
- **弱**:ROE < 10%,商品化竞争,无定价权

### 4. competitors(主要竞争对手列表)
- 输出 0-5 个,每个 `{"name": "...", "ticker": "代码.市场后缀"}`
- A 股 ticker 形如 `000858.SZ` / `600519.SH`,港股 `XXXX.HK`,美股纯字母
- 不知道 ticker 时**整条不输出**(name+ticker 缺一不可,会被过滤掉)

### 5. narrative + evidence
- narrative:200-400 字,说明护城河来源、是否有飞轮、评级理由
- evidence:3-5 条简短数据点,引用 ROE/毛利率/护城河来源/竞品对比

## 严格 JSON 输出契约

只输出 JSON 对象(可包在 ```json 代码块内),禁止额外文字:

```json
{
  "moat_type": "品牌+渠道",
  "moat_flywheel": true,
  "moat_rating": "强 | 较强 | 中 | 弱",
  "competitors": [
    {"name": "...", "ticker": "XXXXXX.SH"}
  ],
  "narrative": "...",
  "evidence": ["...", "..."]
}
```

`moat_rating` 值域必须严格匹配,任何拼写偏差(如"很强"/"middle")将导致解析失败降级。
