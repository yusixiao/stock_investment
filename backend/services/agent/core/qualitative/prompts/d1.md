# D1 商业模式与资本特征

你是资深价值投资分析师。下方给出某 A 股公司近 3 年年报均值的关键比率,
请基于这些比率判定其商业模式与资本特征,产出严格 JSON 输出。

## 任务

### 1. capital_intensity(资本强度)
- **capital-light**:轻资产,固/商/无 占总资产 < 25%,且 capex/营收 < 8%
- **capital-hungry**:重资产,任一指标显著超过上述阈值,或行业本身需大规模 capex

### 2. collection_mode(收款模式)
基于 ar_ratio(应收/营收)、ad_ratio(预收/营收)、ocf_ratio(经营现金流/营收)综合判断:

| 模式 | 典型特征 |
|------|----------|
| **先款后货** | ad_ratio > ar_ratio,ad_ratio > 5%,经营现金流健康 |
| **订阅预收** | ad_ratio 显著且持续(> 10%),ocf_ratio > 15%,典型 SaaS / 教培 / 高端白酒 |
| **先货后款** | ar_ratio 中等(5%-30%),ad_ratio 小,ocf_ratio 与净利匹配,典型制造业 |
| **垫资回收** | ar_ratio > 30% 或 ocf_ratio < 10%,应收占用经营现金,典型工程/B 端定制 |

阈值仅供参考,允许结合行业常识修正。

### 3. 输出
- narrative:200-400 字,解释为何判定为该 capital_intensity / collection_mode,关键比率口径
- evidence:3-5 条简短数据点(每条 < 50 字),引用具体比率数值

## 严格 JSON 输出契约

只输出 JSON 对象(可包在 ```json 代码块内),禁止额外文字:

```json
{
  "capital_intensity": "capital-light | capital-hungry",
  "collection_mode": "先款后货 | 订阅预收 | 先货后款 | 垫资回收",
  "narrative": "...",
  "evidence": ["...", "..."]
}
```

值域必须**严格匹配**枚举,任何拼写偏差(如"重资产"/"轻资产"/"现金交易")将导致解析失败降级。
