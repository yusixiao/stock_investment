# 林奇·隐蔽资产型(asset_plays)· 参数探索综合结论

> 收口 R1→R5 五轮参数探索 + champ 子区间时间稳健性审计。数据口径:全 A 股(~5524 只),
> 回测 2010-01-01 → 2026-06-01,成交价 T+1 次日 (open+close)/2,佣金万三+印花税千一。
> ⚠️ 幸存者偏差:数据仅含当前在市标的,隐蔽资产型(深度破净)受此影响偏乐观。

## 一、冠军配置 K4

```
rebalance_months = [6, 12]     # 半年调仓(6月/12月)
pb_max           = 1.0         # 破净锚:PB ≤ 1.0
tangible_pb_max  = 1.0         # 有形账面折价(剔商誉/无形"虚胖")
require_positive_tbv = True    # 正有形账面价值
require_positive_np  = True    # 正净利润(排除纯亏损壳)
sort_by          = net_cash    # 软倾斜:按净现金率(货币资金−总负债)/市值 降序
mktcap_min_yi    = 50          # 市值下限 50 亿(抗退市)
mktcap_max_yi    = 300         # 市值上限 300 亿(剔巨型银行/价值陷阱)
trend_ma_days    = 150         # 个股趋势滤网:仅买当前价 > 自身150日均线者
top_n            = 20          # 持仓 20 只
```

## 二、参数探索轨迹(全期 2010-2026 口径)

| 轮次 | 冠军配置 | 全期年化 | 关键发现 |
|---|---|---|---|
| R1 粗扫(26配置) | 半年调仓 | 7.58% | 择时/移动止损/行业分散/去有形锚 **全部有害**;低换手单杠杆最稳 |
| R2 收益内核(14) | semi+PB≤1.0+净现金降序 | 11.16% | 净现金要**软倾斜**(sort_by)而非硬门槛(硬 floor 饿死组合→~2%) |

全期 sharpe 0.66 / 最大回撤 33.0% / 447 笔。

## 三、🚨 子区间审计 —— 揭穿全期数字

**三段独立回测(各自从空仓重建),冠军 K4(trend150):**

| 子区间 | 市况 | 沪深300年化 | 策略年化 | 超额(pp) | Sharpe | 笔数 |
|---|---|---|---|---|---|---|
| p1 2010-2015 | — | 0.90% | **26.90%** | +26.0 | 1.26 | **仅 12** |
| p2 2016-2020 | 牛 | **8.49%** | 6.49% | **−2.0** | 0.28 | 109 |
| p3 2021-2026 | 熊 | **−1.54%** | 5.73% | **+7.3** | 0.24 | 322 |
| **2016+ 全子期** | 混合 | 3.26% | **8.38%** | +5.1 | 0.36 | 437 |

**结论:全期 14.73% 是幻觉。**
- 它几乎**全部**来自 2010-2015 那 **12 笔**(年化 26.9%)—— 早期 A 股上市数少、深度破净+趋势确认的机会集极稀薄(PIT 可见年报 2010 仅 ~2000 只),12 笔样本**统计无意义**,再经复利放大整条净值曲线 CAGR。
- 机会集充实后的 **2016-2026,真实年化仅 8.38%**(sharpe 0.36)。这是**可发布的诚实水平**。
- 三变体(trend150 / trend120 / trend150+top25)每段紧密聚类(2016+ 全 8.2-8.4%),结论**稳健非单点**。

## 四、经济本质:防御型逆周期价值

- **熊市 outperformer**:p3(2021-2026,沪深300 −1.54%)策略 +5.73%,**超额 +7.3pp** —— 深度破净+净现金厚+已站上均线,在市场恐慌期抗跌。
- **牛市 laggard**:p2(2016-2020,沪深300 +8.49%)策略仅 6.49%,**跑输 2pp** —— 成长领涨时,防御价值天然落后。
- 全周期(2016+)超额 +5.1pp 主要**赚在熊市**,是典型的"跌得少"型价值策略,非"涨得多"。

## 五、诚实裁决

- **15% 目标在可发布窗口未达成**。全期 14.73% 不可作为预期,真实预期 ≈ **8.4% 年化 / Sharpe 0.36 / 回撤 32%**(2016-2026)。
- 定位:**防御型深度价值卫星仓**,熊市/震荡市抗跌(相对沪深300 稳定超额),不适合追求高绝对收益或牛市 beta。
- 与其他林奇子策略规律一致(周期型全期 11% 亦为 2015 泡沫过拟合、诚实 6.43%):**全期高收益多由个别小样本行情段撑起,子区间审计是防过拟合的必要关卡**。
- 遗留风险:①幸存者偏差(数据仅当前在市,退市破净股缺失,偏乐观);②2016+ 样本换手仍偏低(437 笔/10.5年),单票权重高。
